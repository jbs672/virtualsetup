Etapa 3 - Interface de PC classico (Win95/2000 / XFCE classico)

- Removido Material/AppCompat, ripple e elevacao.
- Menu de contexto customizado (ContextMenuView) no lugar de dialogos nativos.
- Toque longo do papel de parede com Handler + Runnable de 1000 ms e deteccao de arrasto.
- Explorador de arquivos com menu, barra de endereco, Voltar/Avancar/Acima e colunas detalhadas.
- Duplo clique manual por intervalo de tempo.
